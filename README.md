# АУКЦИОН — командная игра про сборку ПК

Мультиплеер-игра для компании: большой экран ведёт аукцион компьютерных
деталей, а команды с телефонов делают ставки, скупают б/у железо на «Авито»,
берут новое в «ДНС» и в любой момент собирают ПК. Побеждает команда с лучшим
финальным бенчмарком, а не та, что накопила денег.

- Большой экран (ведущий): лента лотов, табло сборок, кинематографичный
  бенчмарк, итоги и номинации.
- Телефоны (2 игрока в команде): ставки на торгах, рынки, инвентарь,
  сборка ПК по слотам с проверкой совместимости.
- Ничего не нужно устанавливать на телефоны: всё работает через браузер
  в локальной сети или через интернет после деплоя.

## Правила в двух абзацах

Ведущий создаёт комнату, команды подключаются по коду (до 6 команд по 2
игрока). У каждой команды бюджет 100 000 рублей. На большом экране идут
лоты: новые детали, комплекты 2-в-1 и «кот в мешке» — б/у деталь без
проверки. Команды повышают ставки с телефонов; лот уходит лидеру, когда
все соперники спасовали. Ведущий может продать лот лидеру вручную
«молотком». Параллельно открыты рынки: «Авито» дешевле на 20-45%, но около
30% покупок приходят с браком, «ДНС» продаёт новое с гарантией и выкупает
обратно за 70% цены.

Детали из инвентаря в любой момент ставятся в слоты ПК. Игра проверяет
совместимость: сокеты процессора и платы, тип памяти, мощность блока
питания против потребления сборки, охлаждение против TDP. Несовместимая
или бракованная конфигурация не загружается на бенчмарке и получает ноль.
После торгов ведущий запускает финальный прогон: сборки получают баллы,
объявляется победитель и вручаются номинации («Бухгалтер», «Молот
торгов», «Рисковый»).

## Быстрый старт локально

Требования: Node.js 20 или новее.

    Скачайте версию Local_Game
    npm install
    npm start

Дальше:
Ведущий открывает на компьютере http://localhost:3000 и создаёт игру.


Игровое состояние живёт в памяти процесса: перезапуск сервера сбрасывает
партию. Для домашней или офисной игры этого достаточно.

## Деплой для игры через интернет

Репозиторий готов к деплою на Render и любой другой хостинг с Node.js:

1. Создать Web Service из этого репозитория.
2. Start command: npm start. Сборка не требуется.
3. Порт берётся из переменной окружения PORT, локально по умолчанию 3000.

После деплоя телефоны играют из любой сети по адресу, который выдаёт
хостинг. Добавлены эндпоинт проверки живости GET /healthz и
автовосстановление сессии после обрыва связи: игрок и ведущий возвращаются
в ту же комнату после перезагрузки страницы.

## Структура проекта

    server.js           сервер: комнаты, аукцион, рынки, бенчмарк (socket.io)
    data/catalog.js     каталог деталей, цены и правила совместимости
    public/index.html   оболочка: меню, вход по коду, контейнеры экранов
    public/shared.js    утилиты, звук, иконки, загрузка каталога на клиенте
    public/host.js      большой экран ведущего
    public/player.js    телефон команды
    public/style.css    стили всех экранов

Иконки деталей — inline-SVG в shared.js, внешних ассетов нет.
