# АУКЦИОН — командная игра про сборку ПК

## Запуск
    npm install
    npm start
    → http://localhost:3000

## Как играть
1. Выберите 2–6 команд, введите названия и имена участников.
2. Аукцион: 3 волны по 4 лота. Команды повышают ставки кнопками,
   побеждает последняя ставка до истечения таймера.
3. Между волнами — рынок: Авито (дешевле, ~30% брак, проверка после покупки)
   и ДНС (новое, дороже). Продавать можно за 70% (брак — за 10%).
4. Финальная сборка: детали ставятся в 8 слотов, проверяйте сокет,
   DDR и мощность БП.
5. Бенчмарк решает всё. Победитель — у кого больше баллов.
